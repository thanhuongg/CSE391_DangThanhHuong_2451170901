Phân tích lỗi

Code gốc bị lỗi:

.sidebar  { width: 300px; padding: 20px; border: 1px solid; float: left; }
.content  { width: 660px; padding: 30px; border: 1px solid; float: left; }

Tính chiều rộng thực tế (content-box):

  • Sidebar: 300 + 20×2 (padding) + 1×2 (border) = 342px
  • Content: 660 + 30×2 (padding) + 1×2 (border) = 722px
  • Tổng: 342 + 722 = 1064px > 1000px → content bị đẩy xuống dòng mới!

Cách sửa 1 — Dùng box-sizing: border-box

Width 300px và 660px đã bao gồm padding và border → tổng chính xác = 1000px.

Sidebar

width: 300px (border-box)
Chiều rộng thực = 300px

Content

width: 660px (border-box)
Chiều rộng thực = 660px

Tổng: 300 + 660 + 40 (gap) = 1000px ✅

Cách sửa 2 — Tính toán lại width để bù cho padding/border

Không dùng border-box, nhưng trừ padding và border ra khỏi width:

  • Sidebar muốn rộng 300px: width = 300 - 20×2 - 1×2 = 258px
  • Content muốn rộng 660px: width = 660 - 30×2 - 1×2 = 598px
  • Tổng: (258+40+2) + (598+60+2) = 300 + 660 = 1000px ✅

Sidebar

width: 258px (content-box)
Chiều rộng thực = 300px

Content

width: 598px (content-box)
Chiều rộng thực = 660px

Phân tích Cascade Puzzle:

  1. "Sản phẩm A" (h2.title.highlight trong #featured):
    • font-size: 20px (từ .card .title)
    • color: green (từ .highlight { color: green !important } — !important thắng tất cả kể cả #featured .title)
  2. "Mô tả sản phẩm" (p trong #featured.card):
    • color: blue (inherit từ .card — .card p { color: inherit } → inherit lấy color của .card = blue)
  3. "Sản phẩm B" (h2.title trong .card thứ 2):
    • font-size: 20px (từ .card .title)
    • color: red — SAI. Đúng là blue (từ .card { color: blue }) — .card .title không set color
  4. "Mô tả sản phẩm B" (p.highlight):
    • color: green (từ .highlight { color: green !important })
