Kết luận

Element hiển thị màu DarkRed vì rule #demo.text.highlight có specificity cao nhất (1,2,0) = 120 điểm.

Thay đổi thứ tự CSS có làm đổi kết quả không?

Không, vì tất cả 10 rules target cùng 1 element với specificity khác nhau. Specificity cao hơn luôn thắng, bất kể thứ tự trong file CSS.
Ngoại lệ: Nếu 2 rules có cùng specificity (ví dụ rule 3 và 4 đều là 0,1,0), rule nào viết sau trong file CSS sẽ thắng (cascade tie-breaking).
