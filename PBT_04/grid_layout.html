Phần 3 — Khi nào dùng Grid? Khi nào dùng Flexbox?

✅ Dùng CSS Grid khi:

  • Layout 2 chiều (hàng và cột đồng thời)
  • Bố cục trang toàn trang (header/sidebar/main/footer)
  • Photo gallery, calendar, dashboard
  • Items cần đặt chính xác theo hàng/cột
  • Tạo layout phức tạp không đều nhau

✅ Dùng Flexbox khi:

  • Layout 1 chiều (chỉ hàng hoặc chỉ cột)
  • Navbar, tab bar, button group
  • Căn giữa 1 element trong container
  • Danh sách items có kích thước linh hoạt
  • Component nhỏ bên trong một phần của trang
